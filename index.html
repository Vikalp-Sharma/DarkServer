What is DarkMaxxer?

DarkMaxxer is a standalone, enterprise-grade AI software development environment designed specifically for engineers who demand total hardware autonomy and zero data harvesting. By integrating custom weight-loading algorithms (`airllm`) with PyTorch's secure serialization (`torch.load(..., weights_only=True)`), DarkMaxxer delivers state-of-the-art coding intelligence locally on consumer hardware.

Why Self-Host on Raspberry Pi?

Deploying your DarkMaxxer distribution node onto a Raspberry Pi (`RPI` directory) turns any ARM single-board computer into an always-on team development portal and download mirror. Coupled with `zrok` zero-trust proxy sharing, your developers can stream `DarkMaxxerSetup.exe` across the globe with zero firewall holes or complex VPN configurations.

Raspberry Pi Deployment & The `startserver` Alias

The `RPI` directory inside the DarkMaxxer repository is pre-configured for instant execution on Raspberry Pi OS, Ubuntu ARM, Debian, and DietPi systems.

Step 1: One-Click Alias Installation (`install_alias.sh`)

To register the global `startserver` command on your Raspberry Pi, run our installer utility once:

cd RPI && bash install_alias.sh

This automatically adds `alias startserver='bash /path/to/RPI/startserver.sh'` to your `~/.bashrc` / `~/.zshrc` profiles and creates `/usr/local/bin/startserver` for system-wide access.

Step 2: Launching Your Node (`startserver`)

From any directory on your Raspberry Pi terminal, simply type:

startserver

When executed, `startserver` performs this exact sequence automatically:

  • **Environment & Tool Verification**: Verifies Python 3 and checks if `zrok` is installed (`curl -sSL https://get.openziti.io/install.bash | bash`).
  • **Spawns HTTP Node (`server.py`)**: Launches `python3 server.py --port 8080` in the background with clean process ID tracking (`rpi_server.pid`). Serves the DarkMatter UI and handles chunked file streaming for `DarkMaxxerSetup.exe`.
  • **Initiates zrok Public Proxy**: Runs `zrok share public --backend-mode proxy http://localhost:8080` to generate your secure worldwide HTTPS share link.
  • **Graceful Shutdown (`Ctrl+C`)**: Traps `SIGINT` and `SIGTERM` signals so when you terminate `zrok`, `startserver.sh` automatically shuts down `server.py` and releases port 8080 immediately!

Model Context Protocol (`MCP`) Tool-Calling Guide

DarkMaxxer empowers local AI models to act as autonomous pair programmers. When the AI determines that a code file must be created or modified, it outputs structured tool commands that `_process_tools()` intercepts and verifies.

Explicit Tool Command Syntax

[TOOL: create_file|path/to/script.py|# Python code inside...]
[TOOL: read_file|path/to/script.py]

Intelligent Auto-Fallback Code Extraction

To ensure 100% reliability with smaller local models (such as 3B or 7B GGUF weights) that might output standard markdown code fences instead of explicit `[TOOL: ...]` tags, DarkMaxxer implements smart prompt reachability and auto-fallback:

  • **System Prompt Enforcement**: Sends clear `role: "system"` instructions outlining available tools at the start of every inference pass (`llm_engine.py`).
  • **Regex Code Block Capture**: If your request asks for a new file (`"Create a python file adder.py to add two numbers"`), and the model responds with ` ```python ... ``` ` without the tool prefix, `main.py` automatically captures the code block and creates `adder.py` inside your workspace (`FileOpsServer.create_file()`).
